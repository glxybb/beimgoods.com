What platforms does Beim Goods Livestream TTS support?

Beim Goods Livestream TTS supports several categories of platforms.
Gaming streaming: StreamYard, Twitch, Kick, YouTube Live, YouTube Studio

No. It is less than 70KB and uses the browser’s built in speech synthesis functionality, and it does not run a separate speech processing software. It is designed to not compete for compute cycles.

What languages does Beim Goods Livestream TTS support?

Beim Goods Livestream TTS does not set the language. It uses the user’s browser speech synthesis.

Does Beim Goods Livestream TTS use AI to process my data?

No. Beim Goods Livestream TTS extension reads chat text on the page and passes it to the user's browser's speech synthesis. That's it.

Does Beim Goods Livestream TTS sell my data to advertisers?

No. Beim Goods is a privacy first company. Beim Goods Livestream TTS does not collect or sell user data.

Does Beim Goods Livestream TTS store my chat data?

No. Beim Goods is a privacy first company. No chat data is stored.
