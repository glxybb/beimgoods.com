Use Beim Goods Livestream Chat TTS to Boost Audience Engagement

One of the most given advice by the experienced Poshmark sellers is to interact with the audience. But we all know it is quite difficult to carry on a conversation with viewers via their chats and trying to sell the products at the same time. We are not built to multitask this way. One solution is to let technology convert live chats to audio, so you can listen to chats and have a real convo with your audience. And to set up the chat converter is very easy.


In technology terms, the chat converter is called Text to Speech, TTS. Chat TTS software reads the live chats aloud in real time. To set it up is very simple.


If you host Poshmark Live shows from your phone, you can still utilize Chat TTS software. Just open a laptop, or a computer. Any computer would work, it could be a chromebook, a windows laptop, a mac etc. any computer works. No tablet though.

  • Step 1: Open a chromium based browser. Some common ones that came with the computers preinstalled are Chrome browser and Microsoft Edge. For those who really care about security and privacy, use Vidaldi or Brave.
  • Step 2: Go to Google Chrome Web Store. And search for these words: “Beim Goods Livestream Chat TTS”. Here is the link to the Google Store: Beim Goods Chat TTS
  • Step 3: Install Beim Goods Livestream Chat TTS. If you need more detailed instructions on how to install a browser extension, here is an instruction video on how to install Beim Goods Livestream Chat TTS. Once the extension is installed, you are good to go.

To verify the Chat TTS works, go to a live show. You will see the ‘Beim Goods TTS’ banner at the lower left corner of the web page. You should hear the live chats via your computer speaker. To prevent echo and interference, you want to wear a headset or bluetooth earbuds, so Chat TTS sound does not echo and cause interference. You can also turn the Chat TTS functionality on or off by clicking on the ‘Beim Goods TTS’ banner toggle switch.


If you are already using a laptop or computer to host your Poshmark Live show, you are all set. The Chat TTS and your show can run simultaneously. Even if you are not using Chat TTS, hosting Poshmark live shows on a computer is a better experience anyways. The chat texts are larger, larger screens are easier on the eyes anyways. For example, the Poshmark seller dashboard is larger and easier to read, especially when managing shipping. In situations where you made a mistake typing weight (1oz v.s. 1lb), it is much easier to catch a mistake and correct mistakes on a computer.
