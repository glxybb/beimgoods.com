We have early users that showed us tremendous support and offered us valuable feedback. Thank you all. Here is a common feedback that we are addressing in the latest 1.3.9 update, chat filtering.


During a live stream session, either streamers are playing Fortnite or streaming IRL, it is important to hear audience chats, but also it could get very noisy. Audience cheering on, or just trolls that are spamming the chat box. So we implemented some mechanisms in the software to pass on chats to TTS but also filtering the repetitive messages. The filtering is all executed locally on streamer’s computer, so chat information stays private. Again, user privacy is very important to us.


1. Long runs or tandem repeats are capped

Long runs look like this: ‘w🔥w🔥w🔥w🔥w’. Repeated characters that can be collapsed into a smaller run and offer just as much information. So we capped the run length and filtered out emojis. So ‘w🔥w🔥w🔥w🔥w’ is truncated to ‘www’.


2. Duplicated chats are filtered

Duplicated chats look like this:

  • Chat 1: lol
  • Chat 2: lol
  • Chat 3: lol

In this case, Chat 2 and 3 are ignored by the TTS. The chats are still visible in the chat box, but the TTS would not fire.


With these two updates in place, TTS is much more ‘focused’ and less noisy. Again the filtering algorithm runs locally to protect user privacy. We thank Jose and Dave for offering us feedback!
